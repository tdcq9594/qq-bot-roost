群管能力

禁言 / 撤回已开放；群成员与踢人需官方白名单
官方群管理接口分两档：禁言、撤回、群基本信息对所有机器人开放； 群成员列表、批量移除（踢人）、群黑名单只对白名单机器人开放， 没申请就调会返回 11253。
所以这里默认关闭。去开放平台申请通过后再勾上，勾选后立即生效、不用重启。 没申请而勾上，只会让机器人每次调用都白跑一趟报错。

机器人主人

主人可以使用全部管理命令
不知道 openid？在群里 @机器人 发 /whoami，或用上面的「活跃会话」看。

入群后自动授予的权限

  • 邀请人 → 该群管理员（1 级），只影响这一个群
  • 群主 → 该群管理员（1 级）。群主发过言才能识别（报文里 member_role=owner）
  • 两者都不会获得全局主人或全局管理员
要调整或撤销，去「权限」页改对应的 group:xxx 作用域。 全局主人只能在 config.json 的 owners 里配，或首次启动时用认领码认领。

看不到你的群？官方没有「查询机器人所在群列表」的接口， 群只能靠事件被动发现。请按顺序排查：
  1. 在群里 @机器人 发一句话（不 @ 不会推送消息）
  2. 确认这个群在开放平台「沙箱配置」里（开发中的机器人只收沙箱群消息）
  3. 确认机器人是在它运行期间被拉进群的——离线时入群的事件会丢
  4. 看上面「事件统计」：全是 0 说明平台一条都没推过来

权限等级

作用域决定「在哪管」，等级决定「能管谁」；数字越小权限越高，只能授予数字更大的等级
数字越小权限越高： 0 主人（config.json） 1 管理员 2 群管 3 助手 4-9 内核预留 10+ 插件区 9999 无权限
