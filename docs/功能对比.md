## 四、建议补的（按「性价比 × 留存影响」排）

### 第一批：成本低、影响大

1. **称号佩戴 + 获取途径** —— 已有表，只缺「佩戴」和「怎么拿到」。10 分钟能做完
2. **连续签到** —— 单次签到 → 7 天阶梯，`签到` 已有，加一张 `signin_reward` 表即可
3. **背包搜索** —— `背包 <关键词>`，一行过滤
4. **冥想（挂机经验）** —— `开始冥想`/`结束冥想`，按分钟给经验，复用 `regen` 的 `last_seen` 思路
5. **批量操作** —— `批量 使用 金疮药 5` / `批量 购买`

### 第二批：中等成本、明显延长寿命

6. **斗天任务（战令）** —— 赛季任务 + 积分 + 兑换商店，一张 `battlepass` 表
7. **排位赛季** —— 报名、段位、赛季结算奖励
8. **世界 BOSS** —— 全服共享血量，每天刷新
9. **装备镶嵌（宝石/开孔）** —— 装备深度的核心
10. **装备耐久 + 维修** —— 货币回收（现在后期钱没处花）

### 第三批：大系统，按需再做

11. 万兽台（爬塔）/ 深渊 / 神位传承
12. 功法 / 血脉 / 双生武魂 / 暗器
13. 宗门战 / 领地争夺 / 宗门商店
14. 魂灵/战宠/战魂/斗灵的深化（合成、熔炼、抽取、祈福）

### 明确不建议做

| 功能 | 为什么不做 |
|---|---|
| **仓库 / 仓库扩容** | 背包无上限，加仓库等于凭空造一个限制，是**退步**。要做就做「超量自动进仓库」 |
| **贵族 / 氪金 / 充值** | 需要真实支付通道和资质，而且「禁止收费」是项目底线（见许可） |
| **PK 强杀 + 监狱** | 强 PVP 会劝退新人，文游群体普遍不吃这套 |
| **补位 / 待更** | 麒麟自己没做完的占位指令 |

## 五、一句话总结

麒麟的**功能面比我们宽**（389 个指令词 vs 我们 94），主要在长线运营（战令/赛季/爬塔/世界BOSS）、
装备深度（镶嵌/耐久/锻造）、养成分支（功法/血脉/双生武魂/暗器）、社交外观（称号/送花/匿名）。

我们的**结构比它干净**（归并 + 内容表可编辑 + 数值可验证 + 自动战斗 + 邮件 + 动态引导），
同样的功能用更少的表和更少的指令就能覆盖。

**下一步建议先做第一批 5 个**——都是小改动，但正好补上「留存」和「手感」两块短板。
